# Git Guide

## 1. Git nima?
Git — versiya nazorati tizimi.

## 2. Git nima uchun kerak?
Loyihadagi o'zgarishlarni kuzatish uchun kerak.
## 3. Repository nima?
Repository — loyiha fayllari saqlanadigan joy.

## 4. Global va Local konfiguratsiya farqi
Global barcha loyihalarga, Local esa faqat bitta loyihaga tegishli.

## 5. git init
Yangi Git repository yaratadi.

## 6. git status
Repository holatini ko‘rsatadi.
## 7. git add
Fayllarni commit uchun tayyorlaydi.

## 8. git commit
O‘zgarishlarni saqlaydi.

## 9. git log
Commitlar tarixini ko‘rsatadi.

## 10. git branch
Branchlar ro‘yxatini ko‘rsatadi.

## 11. git switch
Boshqa branchga o‘tadi.

## 12. git merge
Branchlarni birlashtiradi.

## 13. git branch -d
Keraksiz branchni o‘chiradi.
