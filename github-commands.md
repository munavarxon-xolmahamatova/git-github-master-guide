# GitHub Guide

## GitHub nima?
GitHub — loyihalarni saqlash va boshqarish platformasi.

## Repository nima?
Repository — loyiha fayllari saqlanadigan joy.

## Branch nima?
Branch — loyihaning alohida ishchi yo‘nalishi.
## GitHub nima uchun kerak?
GitHub loyihalarni internetda saqlash va boshqalar bilan ishlash uchun kerak.

## Git va GitHub farqi
Git versiyalarni boshqaradi, GitHub esa loyihalarni internetda saqlaydi.

## GitHub account
GitHub account — foydalanuvchining shaxsiy hisobi.

## Public va Private
Public — hammaga ochiq. Private — yopiq repository.

## Remote
Remote — internetdagi repository manzili.

## git remote add
Remote manzilini qo‘shadi.

## git remote -v
Remote manzillarni ko‘rsatadi.

## git push
O‘zgarishlarni GitHub'ga yuboradi.

## git pull
GitHub'dagi o‘zgarishlarni yuklab oladi.

## git clone
Repository nusxasini ko‘chiradi.

## Branchlar
Branch — loyihaning alohida yo‘nalishi.

## Commit
Commit — o‘zgarishlarni saqlash nuqtasi.

## Fayllarni tahrirlash
GitHub orqali fayllarni o‘zgartirish mumkin.

## Branchni o‘chirish
Keraksiz branchni o‘chirish mumkin.
