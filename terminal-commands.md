# Terminal Guide

## 1. Terminal nima?
Terminal — kompyuter bilan buyruqlar orqali ishlash vositasi.

## 2. Terminal nima uchun kerak?
Fayllar va papkalarni boshqarish uchun kerak.

## 3. pwd
Joriy papka manzilini ko‘rsatadi.

## 4. ls
Papka ichidagi fayllarni ko‘rsatadi.

## 5. cd
Boshqa papkaga kiradi.

## 6. mkdir
Yangi papka yaratadi.

## 7. touch
Yangi fayl yaratadi.

## 8. cat
Fayl ichidagi matnni ko‘rsatadi.

## 9. clear
Terminal ekranini tozalaydi.

## 10. cp
Fayldan nusxa oladi.

## 11. mv
Faylni ko‘chiradi yoki nomini o‘zgartiradi.

## 12. rm
Faylni o‘chiradi.

## 13. git init
Git repository yaratadi.

## 14. git status
Git holatini ko‘rsatadi.

## 15. git log
Commitlar tarixini ko‘rsatadi.
